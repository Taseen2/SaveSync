# 📓 SaveSync: Smart Notes App

A minimalist, high-performance note-taking application built with Vanilla JavaScript, featuring real-time auto-saving, category management, and data portability.

![Project Status](https://img.shields.io/badge/Status-Functional-success)
![Technology](https://img.shields.io/badge/Tech-Vanilla%20JS%20%2B%20CSS-yellow)

## ✨ Features

- **🚀 Instant Performance:** Zero dependencies. Pure HTML, CSS, and JavaScript.
- **💾 Persistent Storage:** Automatically saves your notes to `LocalStorage`. Never lose a draft.
- **🌓 Adaptive Theme:** Supports System, Light, and Dark modes with smooth transitions.
- **📝 Markdown Support:** Write using familiar markdown syntax (bold, italic, headers, lists).
- **📂 Organization:** Tag notes with categories, pin important ones, or star your favorites.
- **🔍 Smart Search & Filter:** Instantly find notes by content or filter by status (Recent, Archived, Trash).
- **📤 Data Portability:** Export your entire notebook as a JSON file and import it back anytime.
- **🎯 Interactive UI:** Features custom cursor effects, ripple animations, and drag-and-drop reordering.

## 🛠️ Technology Stack

- **Frontend:** HTML5, CSS3 (Custom Variables, Glassmorphism, Flexbox/Grid)
- **Logic:** Vanilla JavaScript (ES6+)
- **Storage:** Web Storage API (LocalStorage)
- **Accessibility:** ARIA labels, semantic HTML, and keyboard shortcuts.

## 🚀 Getting Started

1. **Clone the repository:**
   ```bash
   git clone https://github.com/yourusername/savesync-notes.git
   ```
2. **Open the project:**
   Simply open `index.html` in your favorite web browser.

## ⌨️ Keyboard Shortcuts

- **`Ctrl + Enter`**: Save current note.
- **`Esc`**: Cancel editing and reset composer.

## 📁 Project Structure

- `index.html`: The core structure and DOM elements.
- `script.js`: Unified application logic, state management, and event delegation.
- `style.css`: Comprehensive design system and animations.
- `js/`: Modular source files (Alternative architecture ready).
